# 绘图提示词预设与独立接口

入口：酒馆中枢 → 绘图 → **03 · 提示词**。

## 提示词预设

- 新建、复制、改名、删除、导入、导出；最后一个预设不能删除。
- 每个预设有按顺序发送的 system / user / assistant 条目，可编辑、停用、上下移动，或设置关键词触发。
- 关键词在“玩家补充要求 + 本次来源正文”中匹配：英文逗号分隔的任一词命中，可额外要求第二组任一词命中；与 st-chatu8 一样区分大小写。
- 兼容 st-chatu8 的 `{ "预设名": { "entries": [...] } }` 上下文预设、旧 `history: [{ user, assistant }]` 格式、请求类型包中的 `context_presets` / `test_context_profiles` / `context_profiles`，以及本项目导出的 JSON。不是 API 配置、角色预设或固定画风预设的通用导入器。
- 单次导入最多 1 MB，总计最多 100 个预设，每个预设最多 200 个条目，每条正文最多 100,000 字符。超限或非法文件会报错，不覆盖现有预设。
- 仅解析白名单文本字段，不加载脚本、请求标头、API 配置或密钥。
- 文本占位符支持 `{{正文}}`、`{{上下文}}`、`{{用户需求}}`、`{{世界书触发}}`、`{{user}}`、`{{char}}`、`{{getvar::变量名}}`。上下文及世界资料来自本项目已有绘图上下文；getvar 仅读取当前会话的字符串/数字/布尔值。其余宿主宏保留原文，不执行变量写入、脚本、资源库或视频功能。
- Claude / Gemini / Vertex / Cohere 要求 system 条目在 user / assistant 之前；界面提供排序。不会为了兼容而暗中改变导入条目的顺序。
- 自动补充本项目的 `<image_prompt>` 输出格式要求，确保后续正面/负面提示词可解析。过大的请求由现有上下文预算检查拒绝。
- **04 · 固定提示词** 的前缀、后缀、负面词和替换规则独立保留，仍在 LLM 整理完后执行。

旧版只有一个系统指令的配置会迁移成默认提示词预设，独立 API 默认关闭。

## 独立提示词 API

关闭：使用当前正文 LLM、密钥，以及当前正文预设的有效采样参数。

开启：独立选择本项目已有的 LLM 供应商，填写根地址、模型、密钥及上下文/回复长度/温度。点击“连接并获取提示词模型”可读取供应商支持的模型列表；无列表端点的供应商会明确提示测试将发送一条简短文本请求。密钥或配置不完整时不会偷偷回退正文接口。

此接口生成的是**绘图提示词**，真正生成图片的 NAI/SD/ComfyUI/OpenAI Image 接口仍在原来的位置设置。

独立提示词密钥按供应商和根地址隔离，仅存在浏览器 sessionStorage/localStorage 或内存中。不开“记住”仅在当前浏览器会话使用。留空保存保留已有密钥；清除通过明确按钮操作。导出的提示词预设和常规配置没有密钥字段。连接测试使用临时输入，不覆盖已保存的配置或密钥；实际生效仍需“保存绘图配置”。

## NovelAI 模型选择

提供 V5 Full/Curated、V4.5 Full/Curated、V4 Full/Curated 和 Anime V3 的内置目录，并保留自定义模型 ID。验证密钥不生成收费图片。

这是**内置模型目录，不是账户实时返回列表**。官方公开文档未提供绘图模型发现端点；`/oa/v1/models` 是文本模型接口，不用于此处。实际模型权限、订阅和费用以 NovelAI 为准。

V4/V4.5/V5 使用结构化 `v4_prompt` / `v4_negative_prompt`，V5 使用 `params_version: 4`，旧模型使用版本 3。SMEA / SMEA DYN / Decrisper 在现代模型下禁用；V5 不发送旧版 Variety 参数。既有图片仓库、参考图和其他供应商流程不变。

## 验证

`npm run test:run`、`npm run build`。

`node scripts/qa-image-prompt-controls.mjs` 使用本机 Edge 无头浏览器验证 1440px/390px 页面、原格式导入、模型发现、NAI 下拉选择、密钥保留、刷新恢复及横向溢出。外部模型与订阅请求使用假密钥和精确 URL mock，不消耗用户 API 额度。可用 `IMAGE_QA_URL` 指定部署地址进行同一套浏览器检查；新建隔离浏览器上下文，不影响玩家现有存档。

真实账户授权、实际模型响应质量和付费出图未在自动化检查中验证。
