# 对话生图系统实施计划

## Phase 1：领域模型与配置（TDD）

1. 为图像配置默认值、逐字段净化、密钥隔离和提示词预设写失败测试。
2. 扩展 `TavernSettings`，并保证旧数据库/内容包归一化不崩溃。
3. 增加 Dexie v3 的 imageJobs/imageAssets 表和仓库方法。
4. 测试中断任务迁移、事务写入与缓存清理。

## Phase 2：提示词流水线（TDD）

1. 测试 `<images>` 与 `image###` 标记提取。
2. 测试替换/删除/前后置顺序和角色作用域。
3. 测试对话上下文构造、世界书摘要、参考图说明和安全截断。
4. 测试结构化 LLM 结果解析与格式失败回退。

## Phase 3：供应商适配（TDD）

1. 定义统一 `ImageProviderAdapter`。
2. 实现并测试 A1111/Forge 请求、进度、资源列表与中断。
3. 实现并测试 ComfyUI 工作流注入、提交、轮询、输出下载与中断。
4. 实现并测试 NovelAI payload、参考图组与错误分类。
5. 实现并测试 OpenAI/Grok 兼容图像请求和多种响应格式。

## Phase 4：服务与上下文

1. 实现 per-session 队列、状态机、取消、重试与刷新中断恢复。
2. 将提示词 LLM 调用接入现有酒馆 API 和审计能力。
3. 扩展 TavernContext 暴露配置、任务、资产与生成操作。
4. 添加自动生图触发去重，避免刷新或 React StrictMode 重复生成。

## Phase 5：UI

1. 新增懒加载酒馆“绘图”面板。
2. 新增提示词/参数/参考图/连接/缓存/预设完整编辑器。
3. 右侧抽屉增加“对话 / 画廊”页签和生成审阅流程。
4. 增加最新图、历史、元数据、下载、删除、取消和重试。
5. 完成响应式、键盘、焦点、低动态和主题适配。

## Phase 6：验证与发布

1. 运行定向测试并修复。
2. 运行全量测试、类型检查、构建和 `git diff --check`。
3. Playwright 验收桌面/手机关键路径和视觉截图。
4. 代码审查安全、数据迁移、并发和可访问性。
5. 提交并尝试推送；若凭据仍不可用，提供精确的本地推送命令与提交哈希。
