# 玩家身份、限时委托、音频与渔获扩展实施计划

> 依据用户既有“前端不再询问、按推荐方案执行”的授权，本计划在设计文档固化后直接执行。每项功能先建立红灯测试，再实现最小完整闭环，并在稳定阶段提交、推送。

## Task 1：玩家身份与存档迁移

**修改：** `src/game/types.ts`、`src/game/data.ts`、`src/game/reducer.ts`、`src/game/game-save-storage.ts`、身份 UI、设置页与相关 CSS。

1. 写 Reducer、v1→v2 存档迁移和身份覆盖层红灯测试。
2. 增加 `playerProfile`、姓名净化与 `SET_PLAYER_NAME`。
3. 实现首次登记、设置页改名、顶栏身份显示和自动存档。
4. 跑定向测试、TypeScript，提交并推送。

## Task 2：酒馆请求统一使用最新姓名

**修改：** `TavernContext`、会话历史、提示词装配/远程剧情引擎及测试。

1. 捕获真实出站请求，先证明既有会话仍会发送旧名字。
2. 在打开与发送阶段读取游戏身份，同步设置/会话显示名。
3. 将玩家姓名写入变量与系统锚点，移除历史抽屉硬编码。
4. 确认完整预设和世界书仍在同一请求中，提交并推送。

## Task 3：可复现的每日限时委托

**新增：** `src/game/quest-engine.ts` 与测试；**修改：** 类型、Reducer、存档、公告板、背包和 NPC 提交 UI。

1. 红灯覆盖每日概率、首日引导、接取截止、多日跳跃、跨年、过期删除、不可绕过提交。
2. 实现模板与实例分离、seed 随机、日界线处理和存档迁移。
3. 更新所有委托界面与通知聚合。
4. 跑定向/全量相关测试，提交并推送。

## Task 4：角色卡界面收敛为立绘库

**修改：** `CharacterPanel.tsx`、酒馆导航、`remote-story-engine.ts`、样式与测试。

1. 红灯断言文字栏不存在、立绘槽位仍可保存。
2. 移除 UI 文字编辑控件，保留兼容字段和导出结构。
3. 禁止隐藏的角色卡长描述重复注入提示词，世界书成为文字唯一入口。
4. 桌面/移动端组件回归，提交并推送。

## Task 5：音频基础设施与设置

**新增：** `src/audio/*`；**修改：** App Provider、设置页、图标/样式与测试。

1. 写设置持久化、BGM Blob、浏览器解锁、点击音效事件委托红灯。
2. 实现 AudioProvider、IndexedDB BGM、Object URL 生命周期和三类合成音效。
3. 增加设置控件、上传反馈与移动布局。
4. 测试配额/不支持 AudioContext/自动播放拒绝降级，提交并推送。

## Task 6：五种鱼、真实钓获与物品闭环

**修改：** `economy.ts`、鱼类纯函数、GameState/Reducer、FishingModal、存档、世界书与测试。

2. 实现确定性挂钩选择与钓获状态。
3. 更新钓鱼 UI、背包、出售、物品审计和世界书。
4. 跑领域测试，提交并推送。

## Task 7：通用礼物与偏好重平衡
