# Galgame 沉浸式对话抽屉与立绘升级设计

## 目标

将 NPC 对话页改为场景优先的视觉小说体验：背景、人物立绘和当前对白占据全部可用区域；会话记录、行动选项与自由输入默认隐藏，通过右侧悬浮对话按钮按需打开。同步升级现有女性 NPC 与魔物娘立绘，使角色保持职业和身份辨识度的同时，呈现更成熟性感、更能体现身材魅力的服装剪裁。

## 对话界面

- 顶部标题、模型状态、全屏、历史和关闭控制保留，但压缩为覆盖在场景上的轻量浮层，不再占用独立网格行。
- Galgame 场景成为对话容器的主画布，始终填满剩余空间；当前人物、地点背景、姓名、对白与上一段/下一段控制继续直接展示。
- 右侧中部新增 48 像素悬浮对话按钮，使用现有 Phosphor 对话图标，具备唯一 ID、`aria-expanded` 与 `aria-controls`。
- 点击按钮打开右侧抽屉。抽屉包含上下文、完整会话记录、推理展示、可选行动、错误提示和自由输入；再次点击、点击关闭按钮或按 Escape 可关闭。
- 抽屉打开时焦点进入抽屉关闭按钮，关闭后回到悬浮按钮；背景场景仍可见，但抽屉内容独立滚动。
- 手机端抽屉从底部弹出，占据接近全宽、最多 72dvh，并为软键盘和底部安全区预留空间；桌面端宽度限制为 420—520 像素。
- `prefers-reduced-motion` 下关闭抽屉位移动画，仅保留透明度变化。

## 立绘资产

- 角色全部明确为成年女性。
- 以现有 PNG 为身份、发型、发色、职业、种族和配色参考，不改变角色核心辨识度。
- 统一使用精细像素风、完整人物构图和成熟性感但不裸露的奇幻农场服饰：更合身的腰线、领口、短裙/开衩、长靴、束腰、透明或轻薄材质点缀，仍符合人物职业与日常行动。
- 生成阶段使用纯色抠图背景，随后转为透明 PNG；不使用文字、水印、地面阴影或场景背景。
- 新图先写入版本化文件，再替换项目引用；全部成品检查尺寸、Alpha 通道和透明角落。

## 验收

- 初次打开对话时抽屉关闭，场景占满内容区，底部不再永久显示红框区域。
- 悬浮按钮可打开/关闭抽屉，操作区功能保持完整，键盘与手机布局可用。
- 全屏模式下同样使用场景优先布局，不产生页面外层滚动。
- 原有对话发送、流式输出、历史、API 错误、精力结算和分镜导航测试继续通过。
- 新立绘能在地点舞台和 Galgame 场景中正常加载，无背景矩形；角色辨识度与职业信息保留。
