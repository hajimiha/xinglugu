# 默认世界书合册与预设槽位精简设计

## 目标

把雾灯谷随游戏发布的四册系统世界书合并为一本“雾灯谷·全域设定集”，使新设备和升级设备的世界书列表都只显示这一册；全部原有条目按原册顺序完整保留。预设中心移除对单角色游戏没有实际操作价值的“预设角色槽位”，同时继续无损保存 SillyTavern `prompt_order` 的全部分组。

## 兼容边界

- 合并来源固定为 `mistvale-world-rules`、`mistvale-village-archive`、`mistvale-calendar-festivals`、`mistvale-production-partners`。
- 合并后的稳定 ID 继续使用 `mistvale-world-rules`，避免角色、会话和外部数据出现第五个默认 ID。
- 条目顺序固定为世界规则、人物地点、岁时庆典、生产伙伴；每个 `LorebookEntry` 对象原样进入结果数组，不重写正文、关键词、次关键词、注释、顺序、概率、位置或启用规则。
- 旧设备只合并数据库中仍存在的默认册；玩家主动删除过的默认册不会复活。任何非默认世界书及其绑定原样保留。
- 角色卡、会话和设置中的四个旧 ID 统一替换为合册 ID并去重。
- 预设仍以兼容层自动选取默认顺序分组进行编辑和装配；未显示的其他分组继续保存在原始设置中，并能随导出文件返回 SillyTavern。

## 数据迁移

默认内容版本从 6 升至 7。迁移在现有 Dexie 事务内完成：读取四册来源，按固定顺序拼接现存条目，写入稳定主 ID，再删除另外三个旧默认 ID；随后映射角色、会话和设置绑定。迁移必须是幂等的，并保留所有玩家自定义条目和字段。

仓库内容包改为不再重复发布独立世界书，只发布绑定到合册 ID 的六位共生伙伴角色卡。已有设备不提高内容包版本，避免覆盖本机立绘；默认内容版本迁移负责完成合册。

## 界面

预设中心“上下文装配顺序”标题区只保留兼容说明，不显示角色槽位标签或选择框。世界书中心无需新增控件；数据迁移后自然只显示一册系统默认世界书，玩家自建世界书仍逐册显示。

## 验收

- 新档只有一本默认世界书，包含四册原有条目总和且顺序一致。
- 升级档的自定义条目、已修改默认条目和自建世界书均保留；旧绑定去重映射成功。
- 预设槽位控件在桌面与手机均不存在，但真实多分组预设导入、编辑默认分组和导出不丢其他分组。
- 全量单元测试、TypeScript、Vite 构建、`git diff --check` 和桌面/手机浏览器回归通过。
