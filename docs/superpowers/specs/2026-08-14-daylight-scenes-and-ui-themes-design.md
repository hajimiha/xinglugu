# 昼夜场景与彩色 UI 主题设计

## 目标

为村庄地图、农场、地点舞台与 Gal 对话舞台提供统一的昼夜视觉：游戏时间 06:00–16:59 使用白天图，17:00–19:59 使用黄昏图，20:00–05:59 使用夜间图。同时在游戏设置中提供独立于游戏时间的彩色 UI 主题，并在当前设备持久化。

## 设计边界

- 只改变场景的光照、天空、窗外亮度、环境色与灯光强度，不移动、增加或删除建筑、道路、家具、田垄、河流等对象。
- 地图交互热区继续使用原有百分比坐标；所有时间版本必须保持相同宽高比和构图。
- 场景时间由存档中的 `minutes` 唯一决定，不读取设备本地时间。
- UI 主题属于设备显示偏好，不写入游戏进度存档；刷新页面后保留，新建游戏或导入存档时不重置。
- 原夜间资产保留为回退；任一变体加载失败时仍可显示原图。

## 时间分段

| 时段 | 游戏分钟范围 | 视觉目标 |
| --- | --- | --- |
| 白天 `day` | 360–1019 | 清晰自然日光、较高可读性、保留像素细节 |
| 黄昏 `dusk` | 1020–1199 | 金橙斜光、紫蓝阴影、室内开始点灯 |
| 夜晚 `night` | 1200–1439、0–359 | 使用现有夜景，灯火成为主要光源 |

边界函数必须对负数、超过 1440 的分钟值进行归一化，保证预览与测试不会崩溃。

## 场景资产架构

- `scene-lighting.ts`：提供 `getScenePeriod(minutes)` 与场景图片选择、预载逻辑。
- `location-scenes.ts`：把每个地点从单个 URL 扩展为 `{ day, dusk, night }` 资产集。
- `VillageMap`、`FarmStage`、`LocationStage`、`TavernDialogue` 统一传入 `state.minutes`，不各自重复时间判断。
- 所有图片使用稳定尺寸声明与异步解码；切换前预载临近时段，切换时只做短暂透明度过渡，不闪白。

## UI 主题

提供四套保持高对比度的深色彩色主题：

1. `forest` 深林鎏金：现有暗绿与金色，作为默认主题。
2. `tide` 潮汐蓝晶：深海蓝、青绿与浅金。
3. `wisteria` 紫藤星砂：靛紫、藤花紫与暖粉金。
4. `blossom` 绯樱晚霞：酒红、玫瑰与琥珀。

主题通过 `document.documentElement.dataset.uiTheme` 和语义化 CSS 变量生效。设置页使用可键盘操作的单选主题卡，卡片展示真实色板；选择后立即预览并保存到 `localStorage`。读取到未知值或存储不可用时安全回退到 `forest`。

## 无障碍与响应式

- 主题卡使用原生单选控件，具有唯一 ID、可见焦点和已选状态。
- 文字与面板对比度维持可读；不使用颜色作为唯一状态提示。
- 移动端主题卡单列或双列自适应，触控目标最小 44px。
- 尊重 `prefers-reduced-motion`，关闭场景淡入与主题卡位移动画。

## 验收

- 05:59/06:00、16:59/17:00、19:59/20:00 六个边界全部映射正确。
- 同一分钟下地图、地点舞台、农场和 Gal 对话返回同一时段资产。
- 刷新后主题仍在；非法存储值回退默认；存储异常不阻止应用启动。
- 桌面与手机无横向溢出，设置页可完整操作。
- 图片变体尺寸和宽高比与原图一致，地图热区不偏移。
