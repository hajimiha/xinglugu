# 雾灯谷：玩家身份、限时委托、音频与渔获扩展设计

## 目标

在不增加后端的前提下，让玩家姓名、酒馆提示词、委托时间、BGM、点击音效、钓鱼与赠礼形成一致、可存档、可审计的前端闭环。现有世界书、预设、正则、变量与请求检查器继续作为 AI 请求的唯一酒馆管线。

## 1. 玩家身份

- `GameState` 新增唯一身份源 `playerProfile`：`name` 与 `hasConfirmedName`。
- 新存档首次进入时显示紧凑的“登记旅人名”覆盖层。姓名必填，去除首尾空格和控制字符，长度限制为 1–20 个 Unicode 字符；不调用浏览器原生弹窗。
- 旧存档迁移后保留所有进度，只补上未确认的默认姓名“旅行者”，让玩家完成一次登记。
- 设置页提供“玩家档案”分区，可随时更名；顶栏以小型身份标签显示当前姓名。
- 新建会话与既有会话每次发出请求时都读取当前玩家姓名。`{{user}}`、变量快照、消息署名和请求检查器必须一致，旧会话不得继续发送创建时遗留的“旅行者”。
- NPC 回复由模型自然使用姓名；系统提示明确“玩家姓名为 {{user}}，可以自然称呼，但不要每句机械重复”。

## 2. 每日限时委托

### 数据模型

- 静态 `QUEST_TEMPLATES` 只定义文案、发布者、需求、报酬和持续天数。
- 动态委托实例记录：`id`、`templateId`、`postedDay`、`acceptedDay`、`deadlineDay`、`status`。
- `id` 由模板 ID 与发布绝对日组合，避免历史记录冲突。
- 存档升级到 v2；v1 静态委托安全迁移，非法模板、非法日期和不可达状态回退或过滤。

### 刷新与过期

- 春 1 日保证出现“雾后新芽”作为新手引导；其后每个跨过的自然日有 65% 概率刷新一份未接委托。
- 随机结果由 `worldSeed + absoluteDay` 计算，Reducer 保持纯函数，同一存档刷新不会改变结果。
- 公告板同时最多保留一份未接委托；午夜旧的未接委托撤下，再决定当日是否刷新。
- 接取时设置截止日。`expiresInDays = 3` 表示接取日及其后两日有效，越过截止日午夜即删除。
- 已接委托过期后直接从活动列表消失，并产生一条聚合通知；已完成记录可保留在历史区。
- `SUBMIT_QUEST` 只接受 `active` 或 `ready` 状态，不能绕过接取直接提交。
- 时间跳跃、旅行、战斗失败与普通过夜全部走同一个日界线函数，因此不会遗漏刷新或过期。

### 界面

- 村长家公告板显示“今日无新委托”“剩余今天/剩余 N 天”“已逾期撤下”等真实状态。
- 背包任务页分为公告板、进行中、完成记录，并显示绝对截止日期。
- 委托刷新与过期不堆叠多条通知，跨多天跳跃只显示摘要。

## 3. 立绘库取代文字角色卡

- 酒馆中枢标签从“角色卡”改为“立绘库”，列表按钮改为“管理立绘”。
- 编辑器只保留好感度区间、图片上传、预览、删除/扩展槽位和保存。
- 人物描述、性格、场景、首句和示例对白不再显示或编辑；这些文字以世界书为唯一内容入口。
- 为兼容 SillyTavern 导入导出，内部 `CharacterCard` 的标准字段仍保留，不破坏已有档案；但远程请求不再把旧角色卡描述重复注入提示词。
- 新会话需要的开场语由世界书、预设和交互上下文共同构造，不依赖隐藏的角色卡编辑栏。

## 4. BGM 与点击音效

### 存储与播放

- 音频偏好单独保存，不放进游戏规则或游戏存档，避免导入存档覆盖本机音量。
- BGM 文件以 `Blob` 存入 IndexedDB；刷新后仍可使用，支持 MP3、OGG、WAV、M4A/AAC。无单文件硬上限，但捕获浏览器配额失败并以内联提示说明。
- 浏览器自动播放受限时显示“等待首次交互”，首次点击后解锁并开始循环播放。
- 替换或移除 BGM 时释放旧 Object URL，组件卸载也清理，防止内存泄漏。

### 音效

- 不下载外部音效。使用 Web Audio 合成短促的像素酒馆音：普通点击、确认、关闭/取消三种包络。
- 全局事件委托覆盖按钮、可点击卡片和标签；文件选择、滑杆、禁用控件与 `data-sound="off"` 不触发。
- 支持系统 `prefers-reduced-motion`，但音效是否播放只由音频设置控制。

### 设置界面

- 新增主音量、BGM 音量、音效音量、静音、启用 BGM、试听音效、上传/替换/移除 BGM。
- 所有滑杆均有数值标签和唯一 ID；桌面与移动端均使用至少 44px 触控目标。

## 5. 五种鱼与钓鱼结果

| 鱼类 | 体型 | 主要水域 | 售价 | 定位 |
|---|---|---|---:|---|
| 银鳞鲫 | 小型 | 河湾、码头 | 95 | 常见入门鱼 |
| 月尾鱼 | 小型 | 林间河 | 120 | 夜色鳍光 |
| 青苔鳟 | 中型 | 林间河 | 180 | 中阶礼物 |
| 潮纹鲈 | 中型 | 海湾 | 240 | 中阶海鱼 |
| 雾湾巨鲶 | 大型 | 深水区 | 480 | 高级稀有鱼 |

- `ItemDefinition` 增加鱼类体型与水域元数据；物品审计、商店出售、背包和世界书都读取同一目录。
- 开始钓鱼时由水域、鱼竿等级、钓鱼等级和随机数确定挂钩对象；浮标只提示“小/中/大型鱼影”，不提前泄露名称。
- 正确收杆取得该鱼；过早取得水草；过晚为空。鱼饵在开始钓鱼时消耗一次。
- 中大型鱼给予更多经验；高级鱼竿和技能提高中大型鱼权重，但不保证必出。
- 存档只接受五种鱼的合法挂钩/最近结果，旧的银鳞鲫记录无损保留。

## 6. 礼物平衡

- 莓果挞改为所有 NPC 的通用喜爱礼物，基础好感收益 10。
- 专属偏爱仍为 14；生日倍率继续在 Reducer 统一计算，界面不再传入可信好感数值。
- 月铃花只保留洛岚与芙蕾雅两人偏爱。
- 原莓果挞/月铃花偏好重新分配：
  - 米拉：月尾鱼、潮纹鲈
  - 桃弥：青苔鳟、铜锭
  - 塞拉：潮纹鲈、史莱姆粘液
  - 达芙：月尾鱼、魔力药剂
  - 凛：铁锭、雾湾巨鲶
  - 苏槿：青苔鳟、雾湾巨鲶
- 赠礼列表同时展示“角色偏爱”和“全员通用”，重复项去重；世界书同步写明而不依赖 UI 隐藏知识。

## 7. 性能、无障碍与错误处理

- Audio Context 对外值 memoize，滑杆更新只修改音频节点与本地设置，不触发游戏状态重算。
- 动态委托与鱼类选择使用纯函数；时间跨多日时线性处理天数，但通知聚合为一条。
- 姓名、BGM、委托和钓鱼都使用内部提示，不调用 `alert`、`confirm` 或 `prompt`。
- 保持语义化表单、可见焦点、键盘提交、无 emoji、统一 Phosphor 图标、150–300ms 过渡和 `prefers-reduced-motion`。
- 验收尺寸：1440×1000、1024×768、390×844、375×667；无页面级横向滚动、重复 ID 或不可达按钮。

## 8. 验收边界

- 捕获真实模型请求，确认预设条目、世界书、最新玩家姓名和 `{{user}}` 替换均存在，且“旅行者”不再泄漏。
- 连续推进日历验证无委托、刷新、接取、倒计时、跨截止日消失和跨年行为。
- 刷新浏览器验证姓名、委托、音频设置与 BGM 均持久化。
- 检查立绘库没有任何人物文字编辑栏，但区间立绘上传、保存、导出仍可用。
- 五种鱼均可被钓到、出售、赠送并在物品审计中有明确来源和用途。
