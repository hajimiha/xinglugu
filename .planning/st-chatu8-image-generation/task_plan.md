# 对话生图完整移植计划

## 目标

将 st-chatu8 的“对话文本 → 绘图提示词 → 本地或远程模型生图 → 图像历史与展示”能力，按本项目既有酒馆、GAL 对话和响应式设计原生重构，并将生成结果集成到右侧“对话与行动”抽屉。

## 边界与原则

- 以 st-chatu8 仓库和作者教程为功能基线，先建立能力清单再实现。
- 不依赖 SillyTavern 宿主页才能运行；复用本项目现有预设、世界书、变量与对话上下文。
- 本地模型走浏览器可达的本机地址；远程模型按供应商能力选择浏览器直连或项目 API 代理。
- API 密钥不进入对话、世界书、内容包、云存档或日志。
- 图像任务有明确的排队、生成、失败、取消、重试和历史状态。
- 新 UI 使用全中文、现有图标系统、键盘可达且适配手机。

## 阶段

- [completed] 1. 审计上游仓库、教程与当前项目，形成兼容能力矩阵
- [completed] 2. 编写设计规格、数据结构、供应商协议和安全边界
- [completed] 3. 先写失败测试：配置、提示词、任务状态、供应商、持久化、UI 交互
- [completed] 4. 实现生图领域层、持久化与供应商适配器
- [completed] 5. 集成对话回复、手动生成、右侧抽屉画廊与完整设置界面
- [completed] 6. 响应式、无障碍、错误恢复、性能和安全加固
- [completed] 7. 全量测试、生产构建、人工桌面/手机验收与代码审查
- [in_progress] 8. 提交并推送（若当前 Git 凭据允许）

## 验收标准

- 能从当前 NPC、地点、时间、最近对话和用户补充要求生成结构化绘图提示词。
- 支持至少上游明确列出的本地与 API 生图路径，配置、测试连接和错误提示齐全。
- 自动/手动生图均可控；任务可取消、重试，刷新后历史仍在。
- 右侧抽屉能展示当前图、历史、提示词、任务进度与生成操作，不阻塞原有对话输入。
- 手机端可完整操作，抽屉、设置和图像查看不存在裁切或滚动死区。
- 密钥、任意远程 URL、超大响应和非图像内容均有保护。
- 定向测试、全量测试、构建和差异检查全部通过。
