# 日夜场景与彩色主题任务计划

## 目标
为村庄地图、农场和全部地点背景补充严格保留构图的白天/黄昏版本，并按游戏内时间自动选择白天、黄昏、夜晚资源；同时提供多套可持久化的彩色 UI 主题。

## 阶段
- [x] 盘点全部场景资源、引用点、时间模型和设置架构
- [x] 写入并自审设计规格，明确时间分段、主题令牌与回退策略
- [x] 以失败测试固定时间分段、资源解析、主题持久化与设置交互
- [x] 使用内置 ImageGen 逐张编辑白天/黄昏场景并校验构图和尺寸
- [x] 实现场景自动切换、资源预加载和主题选择界面
- [x] 完成桌面/手机视觉验收、全量测试、构建、代码审查
- [ ] 提交并推送 main，检查线上部署

## 决策
- 时间分段：白天 06:00–16:59；黄昏 17:00–19:59；夜晚 20:00–05:59。
- 现有深色场景保留为夜晚版本；新增文件不覆盖原图。
- 场景时间与 UI 主题解耦，避免玩家选择的主题被游戏时间覆盖。
- 若个别变体加载失败，必须回退现有夜晚图而非出现空白。

## 错误记录
| 错误 | 处理 |
|---|---|
| 2026-08-14 网络中断 | 用户确认网络恢复后续接，不重复已完成的 OAuth 工作。 |
| ImageMagick `magick` 不可用 | 改用 `view_image` 与 Pillow 进行只读检查和最终校验。 |
| 旧 `node_modules` 权限异常 | 保留原目录并用锁文件重装依赖；使用无配置的 Vitest 程序入口完成同一测试集。 |
| 全量测试误扫依赖备份 | 将正式全量范围限定为 `src/` 与 `api/`，88 个测试文件全部通过。 |
