# 调研记录

- 用户明确要求：不改变场景中的物体与构图，只调整光照、色调和颜色生成白天、黄昏版本。
- 新增要求：不同时间段的地图与背景必须根据游戏内时间自动显示。
- 初始推荐分段为白天 06:00–16:59、黄昏 17:00–19:59、夜晚 20:00–05:59。
- UI 需要多套彩色主题并在设置中选择，选择结果持久保存。
- 当前核心场景资源位于 `src/assets/pixel/`，包括 `village-map.webp`、`farm-dusk.webp`、`location-atlas.webp` 和 6 张独立地点背景（医院、猎人帐篷、图书馆、村长家、魔物娘商店、铁匠铺）。
- `VillageMap.tsx` 直接导入单张 `village-map.webp`；`FarmStage.tsx` 直接导入 `farm-dusk.webp`；`location-scenes.ts` 是地点背景集中解析点，未匹配地点回退 `location-atlas.webp`。
- 地图与场景当前均没有按 `state.minutes` 切换的资源层。
- 现有 `magick` 命令不可用，后续图像尺寸/格式校验改用工作区 Python/Pillow 或 `view_image`，不重复该命令。
- 最终时间规则由 `src/visual/scene-lighting.ts` 单点维护，非法、负数和跨日分钟也会稳定归一化。
- 资源预加载只加载当前时段与下一时段，避免初次进入同时下载同一场景的三张大图。
- 主题使用语义 CSS 令牌覆盖游戏主界面、模态框、酒馆中枢与创意工坊，不与场景昼夜绑定。
- 生产构建中最大新增单图约 696 KB；按当前场景族按需请求，不会在首屏一次下载全部 27 张。
